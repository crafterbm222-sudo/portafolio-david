# Portafolio de David Andrés Bustamante Mesa

Mi portafolio académico con los proyectos y aprendizajes del curso de desarrollo web. Está hecho con HTML, CSS y JavaScript.

- [Ver el portafolio](https://crafterbm222-sudo.github.io/portafolio-david/)
- [Wireframe en Figma](https://www.figma.com/design/tu6biTJQiJgsIMtqQpnyrU)

## Cómo abrirlo

Descargar y extraer los archivos, y abrir `index.html` en el navegador. No necesita Node.js. Mantener las carpetas junto al archivo principal.

## Contenido

Incluye presentación, sobre mí, habilidades, proyectos y contacto. Las tarjetas tienen capturas de mis trabajos y enlaces a las demos de Facebook, ToDoList, catálogo, juego de reacción y buscador de personajes. Las consultas a las API necesitan Internet.

El formulario prepara un correo para revisar y enviar desde la aplicación de correo del visitante. Los datos de ToDoList se guardan solamente en el navegador: usar cuentas de prueba.

El código original del catálogo y del juego está en `fuentes-react`. Sus demos compiladas están en `proyectos`. Los detalles de uso están en `README.txt`.
