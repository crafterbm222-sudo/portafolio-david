RÉPLICA DE FACEBOOK
===================

Este proyecto es una réplica visual académica de la página de inicio de Facebook.
Está realizado solamente con HTML5, CSS y Bootstrap 5. No utiliza JavaScript.

Archivos y carpetas:
- index.html: estructura semántica de la página.
- css/styles.css: estilos personalizados y variables CSS.
- assets/: imágenes locales y captura de la página original.

Elementos aplicados:
- Etiquetas header, nav, main, section, aside, article y footer.
- Bootstrap 5 integrado mediante CDN.
- Grid de Bootstrap con container-fluid, row y columnas col-*.
- Componentes navbar, cards, badges y botones.
- Flexbox en la barra, menús, historias, publicación y contactos.
- Breakpoints para celular, tablet y computador.
- Variables CSS dentro de :root.

Para ver el proyecto, abra index.html en un navegador con conexión a Internet.
La conexión es necesaria para cargar Bootstrap y Bootstrap Icons mediante CDN.
